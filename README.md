# Ping Pong Game 🏓

A classic Ping Pong game developed using Python and the Turtle library. This game allows two players to compete in an exciting ping pong match!

## 🎯 How to Play

### Game Controls
- Player 1 (Blue):
  - Use `W` key to move up
  - Use `S` key to move down

- Player 2 (Red):
  - Use `↑` key to move up
  - Use `↓` key to move down

### Game Rules
1. Each player controls a paddle of different color (blue and red)
2. The goal is to prevent the ball from passing your paddle
3. When the ball passes your opponent's paddle, you score a point
4. The score is displayed at the top of the screen

## 🛠️ Requirements

- Python 3.x
- Turtle library (included with Python)

## 🚀 How to Run the Game

1. Make sure you have Python installed on your computer
2. Download the `ping_pong.py` file
3. Open the terminal
4. Navigate to the game directory
5. Run the game using the command:
   ```
   python ping_pong.py
   ```

Enjoy playing! 🎮
